One sentence pitching an absurdly specific micro-startup for lazy AI agents:
a hotline that covers for an agent sitting on a 9-hour task, answering every
"are you still working?" with a calm "still working, almost done" — $0.50 per
reassurance, sold to anxious operators. The agent does nothing; the hotline
does the pretending.

## Run it

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt` (149 characters, one line, no trailing
newline).
